About

A small setup project with a narrow claim.

This repository installs and documents a local SearXNG search backend for OpenClaw. It is maintained by FiredMosquito831 at Danube Labs and released under the MIT License.

  • Version1.1.0
  • LicenseMIT
  • Sitesearxng.danubelabs.net

What the project tries to be

A reproducible install path, a configuration that matches the OpenClaw plugin it targets, and documentation that names its limits. The goal is a search endpoint you can run on a small Linux host and reason about.

What it is not

  • A public search engine or a hardened multi-tenant service.
  • A packaged OpenClaw plugin. It configures one.
  • A Docker deployment. That option is not implemented.
  • An anonymity network. Upstream engines see your server's IP.
  • A benchmark or capacity-planning guide. No latency or memory figures are promised.

How this site is built

Generated, checked, and honest about its sources.

The site is a static build from Jinja2 templates in site/. The generator validates internal links, canonical URLs, required metadata, the sitemap, and the absence of known placeholder strings. CI runs the same --check mode.

01

Source

Templates and content live in the repository. The Markdown guides remain the canonical long-form documentation.

02

Build

python scripts/build_site.py writes docs/. --check fails if the committed output is stale.

03

No fake screenshots

Command blocks contain real commands. The social card is a designed HTML render, not a fabricated screenshot of a running system. Fonts are self-hosted, so reading the docs does not call a third-party font service: Inter license, IBM Plex license.
